PROMPT DE CRÉATION DU SITE WEB

Crée un site web professionnel complet nommé :

WAB Global Consulting

Slogan :

Clarity. Guidance. Confidence.

OBJECTIF DU SITE

Créer un site institutionnel professionnel destiné à informer, éduquer et accompagner les particuliers qui souhaitent :

* Comprendre les investissements numériques
* Obtenir une analyse préliminaire de leur situation
* Recevoir un accompagnement dans la compréhension des procédures liées aux actifs numériques
* Vérifier certains éléments avant une prise de décision
* Accéder à des ressources éducatives de qualité

Le site ne doit jamais promettre de gains financiers, de récupération de fonds ou de résultats garantis.

Le site doit rester conforme aux politiques publicitaires de Meta (Facebook et Instagram).

⸻
