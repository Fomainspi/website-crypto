# website-crypto

https://chatgpt.com/share/6a242082-b24c-83ec-97ce-759365e94ed4

Crée un site web statique professionnel en HTML, CSS et JavaScript pur (sans framework) pour une activité de conseil et d'accompagnement en investissements numériques et cryptomonnaies.

Objectifs du site :
- Présenter les services de consultation et d'accompagnement.
- Informer les visiteurs.
- Générer des leads.
- Permettre aux visiteurs de contacter facilement le consultant.
- Inspirer confiance et professionnalisme.

Contraintes techniques :
- Site statique uniquement.
- Aucun backend.
- Aucune base de données.
- Responsive mobile, tablette et desktop.
- Design moderne, professionnel et rassurant.
- Optimisé pour le référencement SEO.
- Structure claire et facilement maintenable.
- Utiliser uniquement HTML5, CSS3 et JavaScript vanilla.

Créer les pages suivantes :

1. Accueil (index.html)
- Hero section avec slogan professionnel.
- Présentation du service.
- Bouton "Demander une consultation".
- Bouton WhatsApp flottant.
- Section "Pourquoi nous choisir".
- Appel à l'action.

2. À propos
- Présentation du consultant.
- Mission.
- Valeurs.
- Expertise.
- Approche de travail.

3. Services
Présenter :
- Consultation avant investissement.
- Analyse de situation.
- Assistance concernant les procédures de retrait.
- Vérification préliminaire de plateformes.
- Accompagnement personnalisé.

4. FAQ
Questions fréquentes :
- Comment fonctionne une consultation ?
- Quels types de situations peuvent être analysées ?
- Comment prendre rendez-vous ?
- Quels sont les délais de réponse ?

5. Contact
- Formulaire de contact compatible Formspree.
- Champs :
  * Nom complet
  * Téléphone
  * Email
  * Pays de résidence
  * Objet de la demande
  * Description de la situation
- Bouton WhatsApp.
- Adresse email de contact.

6. Politique de confidentialité
Inclure :
- Données collectées.
- Utilisation des données.
- Protection des informations.
- Droit de suppression.
- Coordonnées de contact.

Fonctionnalités supplémentaires :
- Menu de navigation responsive.
- Footer professionnel.
- Icônes modernes.
- Animations légères.
- Bouton retour en haut.
- Bouton WhatsApp flottant sur toutes les pages.
- Validation JavaScript du formulaire.
- Meta tags SEO complets.
- Open Graph pour Facebook.
- Favicon.

Design :
- Couleurs professionnelles (bleu marine, blanc, gris clair).
- Style cabinet de conseil.
- Sections bien espacées.
- Cartes de services modernes.
- Typographie professionnelle.

Livrables :
- Structure complète des dossiers.
- Tous les fichiers HTML.
- Un fichier CSS principal.
- Un fichier JavaScript principal.
- Images placeholders.
- Commentaires dans le code.
- Instructions de déploiement sur GitHub Pages, Netlify et Vercel.

Le site doit être prêt à être publié immédiatement après personnalisation du contenu et des coordonnées.
